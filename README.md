# UPVET Lavras

Site institucional e catálogo demonstrativo da unidade UPVET Lavras, com páginas para produtos prontos, solicitação de manipulação e acompanhamento de pedidos.

## Site publicado

A versão pública está em:

**https://duduwwl.github.io/upvet-lavras-site/**

O conteúdo completo publicado pelo GitHub Pages fica em `docs/`. O workflow `.github/workflows/pages.yml` faz a implantação automática da branch `main`.

## Escopo da demonstração

- Os preços são ilustrativos e não representam ofertas da farmácia.
- Pedidos, receitas de teste e alterações da gerência ficam somente no IndexedDB do navegador.
- Nenhuma mensagem é enviada ao WhatsApp; o resumo fica preparado para uma futura integração com a API oficial.
- A senha da gerência é fictícia e existe apenas para testar a interface.
- Não devem ser usados nomes, receitas ou dados reais nesta versão pública.

## Páginas

- Página inicial e informações da unidade
- Catálogo responsivo de produtos prontos
- Solicitação de manipulação com anexo de receita fictícia
- Gerência demonstrativa de pedidos e status
